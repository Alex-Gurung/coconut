# Legacy Scripts

These top-level helpers were kept for historical runs and one-off research
workflows. They are not the primary entry point for the repo.

Primary workflow:

- `experiments/gsm_hard_qwen3_4b/train.sh`
- `experiments/gsm_hard_qwen3_4b/smoke.sh`
- `experiments/gsm_hard_qwen3_4b/eval_all.sh`

This directory mainly contains:

- Flawed Fictions pipeline helpers
- older sweep launchers and analysis helpers
- run wrappers tied to retained legacy configs under `args/legacy/`
